## Version 0.1.3 Alpha 1 · 64-bit Windows

A pre-release for testing.

| Package | Download | How to use |
| --- | --- | --- |
| Installer | [GT100-USB-Editor-0.1.3-Setup.exe](https://github.com/gabrielrc99/gt100-usb-editor/releases/download/v0.1.3-alpha.1/GT100-USB-Editor-0.1.3-Setup.exe) | Run it and follow the instructions. Installation is per-user. |
| Portable | [GT100-USB-Editor-0.1.3-Portable.zip](https://github.com/gabrielrc99/gt100-usb-editor/releases/download/v0.1.3-alpha.1/GT100-USB-Editor-0.1.3-Portable.zip) | Extract the ZIP and run `GT100-USB-Editor-Portable.exe`. |

To download in your browser, use the links above or open the release's **Assets** section. You do not need to install Git.

To connect the processor, install the [BOSS GT-100 USB driver compatible with your Windows version](https://www.boss.info/us/support/by_product/gt-100/).

With the portable version, keep the **GT100-data** folder when moving or updating the application. With the installed version, data is stored in `%LOCALAPPDATA%\GT100-USB-Editor`. Instructions and license notices are included in the packages.

The application uses the [MIT license](../LICENSE), included in both the portable package and the installer. Dependencies retain their own licenses. Source code will be made available at a later stage.
