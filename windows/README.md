## Versão 0.1.3 Alpha 1 · Windows 64 bits

Pré-lançamento para testes.

| Pacote | Download | Como usar |
| --- | --- | --- |
| Instalador | [GT100-USB-Editor-0.1.3-Setup.exe](https://github.com/gabrielrc99/gt100-usb-editor/releases/download/v0.1.3-alpha.1/GT100-USB-Editor-0.1.3-Setup.exe) | Execute e siga as instruções. A instalação é por usuário. |
| Portátil | [GT100-USB-Editor-0.1.3-Portable.zip](https://github.com/gabrielrc99/gt100-usb-editor/releases/download/v0.1.3-alpha.1/GT100-USB-Editor-0.1.3-Portable.zip) | Extraia o ZIP e abra `GT100-USB-Editor-Portable.exe`. |

Para baixar pelo navegador, use os links acima ou abra a seção **Assets** da release. Não é necessário instalar Git.

Para conectar a pedaleira, instale o [driver USB BOSS para GT-100 compatível com seu Windows](https://www.boss.info/us/support/by_product/gt-100/).

No portátil, preserve a pasta **GT100-data** ao mover ou atualizar o programa. Na instalação, os dados ficam em `%LOCALAPPDATA%\GT100-USB-Editor`. Instruções e avisos de licenças acompanham os pacotes.

O aplicativo usa a [licença MIT](../LICENSE), incluída no portátil e no instalador. As dependências mantêm suas próprias licenças. Os fontes serão disponibilizados em uma próxima etapa.
